# /trend/ 走勢資料更新紀錄

這裡只記走勢頁與首頁圖表的資料與站務變動。11 項燈號的規則與門檻不在這裡，請看 `rules.md`。

## 2026-11-14 走勢資料改為自動更新（燈號規則未改，仍是 v3.0）

- SOX（`^SOX`）、NDX（`^NDX`）、SPX（`^GSPC`）的走勢與首頁型態資料，改由 GitHub Actions 的「更新訊號資料」工作在既有排程自動產生：台北時間平日 06:30、15:00、22:00，以及手動觸發。
- 產生程式：`scripts/update_trend.py`（抓 Yahoo、寫檔）與 `scripts/trend_analyze.py`（計算）。計算是原本那份分析程式的移植，擺動點、均線、趨勢線、3% 濾網、道氏週線結構、形態檢查的算法和參數都沒有改。
- 產生檔：
  - `trend/data.json`：`{analysis, charts}`。
  - `trend/data.js`：同一份內容包成 `window.SITE_DATA = …;`，給頁面的 `<script>` 用。
  - `trend/status.json`：每次都會寫，記這次有沒有成功、行情截至日、上次成功的時間。
- Yahoo 抓不到或資料有問題時，不覆寫 `data.json`／`data.js`，沿用上次成功的版本；`status.json` 標成過期，首頁與走勢頁會出現一行過期提醒。即使排程完全沒跑，資料超過 3 天沒抓、或行情截至日超過 5 天，頁面也會自己提醒。
- 美股還沒收盤時（例如台北 22:00 那次），進行中的當日 K 不採用，行情截至日是上一個已收盤的交易日。
- 新增 `analysis.indices[SOX|NDX|SPX].home_pattern`：首頁型態小圖的挑選結果，規則與原本首頁的挑選邏輯相同（升勢線有效跌破、線下未達 3%、其餘通用示意），沒有新增三角形、頭肩、雙重頂等判定。
- 走勢頁原本寫死的日期與敘述（抓取時間、截至日、三指數對照的觀察）改由資料組出來。
- 行情原始檔只放在 `data/cache/trend/`（不進版控、不部署）。本機可用 `python scripts/update_trend.py --offline` 以快取重算。
- 原因：首頁與 /trend/ 的圖表原先是 2026-11-13 的靜態快照，無法隨行情更新。
